# Cross-Source Correlation

## Relationship classes
1. Exact identifier match.
2. Structural relation.
3. Content or cryptographic-hash match.
4. Temporal co-occurrence.
5. Contextual similarity.

A strong-looking match may not be independent if sources copy the same original record. Record lineage and common origin; prefer independent corroboration.

For each link record source A/B, matching fields, relation class, exact rule, common-source dependency, alternatives, confidence and limitations.

Never turn co-occurrence into causation without a separate causal argument.
