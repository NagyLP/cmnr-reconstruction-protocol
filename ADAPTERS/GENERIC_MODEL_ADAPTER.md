# Generic Model Adapter

Use when a model can receive instructions but may not browse GitHub.

Onboarding: confirm which protocol files were actually received or accessed. If the repository URL cannot be opened, do not claim to have read it; ask for the prompt/files to be pasted or uploaded. Record the protocol version. Apply the output schema and scoring rubric.

Record model context-window constraints, repository browsing, file uploads, tools/permissions, instruction hierarchy, persistence of custom instructions and whether actual fine-tuning occurred.

Compatibility principle: adapt formatting, not evidentiary standards. Do not weaken provenance, uncertainty, negative-evidence or logical-consistency requirements.
